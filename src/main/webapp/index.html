Understanding Topic vs Queue

Concept

Point-to-Point (Queue)

Each message is delivered to exactly one consumer. Messages remain buffered in the JEUS queue until a consumer acknowledges them or they expire.

Publish/Subscribe (Topic)

Each message is broadcast to all active subscribers listening to the topic at that instant. If there are no subscribers, the message is dropped unless a Durable Subscription is registered.

Configuring JMS Resources in JEUS 8.5 WebAdmin

Step-by-Step Guide
1

Access JEUS WebAdmin

Log in to the JEUS WebAdmin console (typically at http://<jeus-host>:9736/webadmin/ or your administrator port).

2

Navigate to JMS Engine Configuration

Go to: Servers → Select your server (e.g. server1) → Engine → JMS Engine → Resource.

Ensure the JMS Engine is enabled and running on the target server.

3

Connection Factory JNDI Name

JEUS ships with pre-configured default factories bound under the root context:

  • Default Factory: ConnectionFactory
  • XA Factory: XAConnectionFactory
4

Default Destination JNDI Names

JEUS provides default example destinations ready out-of-the-box:

  • Point-to-Point Queue: ExamplesQueue (or JEUSMQ_AMQPQ, JEUSMQ_DLQ)
  • Publish / Subscribe Topic: ExamplesTopic
6

Activate Changes

Click the Lock & Edit → Activate Changes button on the top-left of the WebAdmin console to apply changes to JEUS.

Once activated, switch back to the Queue Studio tab in this console and click "Test JNDI Lookup" to verify!
